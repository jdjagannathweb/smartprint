ଅଦରକାରୀ ଟେଷ୍ଟ୍ ଫାଇଲ୍ ଏବଂ ଭାରୀ .exe ଫାଇଲ୍ ସବୁ ଡିଲିଟ୍ ହୋଇସାରିଛି।

------------------------------------------------------------------------
STEP-BY-STEP କିପରି GITHUB ରେ UPLOAD କରିବେ:
------------------------------------------------------------------------

1. ଆପଣଙ୍କ GitHub ଖୋଲନ୍ତୁ (ଜେଉଁଠି Render ର ପ୍ରୋଜେକ୍ଟ ଲିଙ୍କ୍ ଅଛି):
   - ଉଦାହରଣ: https://github.com/YOUR_USERNAME/YOUR_REPO_NAME

2. ଉପରେ ଥିବା "Add file" ବଟନ୍ ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ -> "Upload files" ବାଛନ୍ତୁ।

3. ଏହି ଫୋଲ୍ଡର (SMARTPRINT_GITHUB_UPLOAD) ଭିତରେ ଥିବା ସମସ୍ତ ଫାଇଲ୍ ଏବଂ ଫୋଲ୍ଡରକୁ
   ସିଲେକ୍ଟ କରି (Ctrl + A) ସିଧାସଳଖ GitHub Browser Window ଉପରକୁ ଡ୍ରାଗ୍ (Drag & Drop) କରନ୍ତୁ।
   (କିମ୍ବା SMARTPRINT_PROJECT_LATEST.zip କୁ Extract କରି ତାର ସମସ୍ତ ଫାଇଲ୍ ଡ୍ରାଗ୍ କରନ୍ତୁ)

4. ତଳେ ଥିବା ସବୁଜ ରଙ୍ଗର "Commit changes" ବଟନ୍ ଦବାନ୍ତୁ।

5. କାମ ଶେଷ! Render.com ୧ ରୁ ୨ ମିନିଟ୍ ମଧ୍ୟରେ ଆପେ ଆପେ ନୂଆ କୋଡ୍ ଲାଇଭ୍ (Auto-Deploy) କରିଦେବ।
